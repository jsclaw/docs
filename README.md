# jsclaw docs

Documentation for [jsclaw](https://github.com/jsclaw/jsclaw), served at [jsclaw.dev/docs](https://jsclaw.dev/docs/) from the `gh-pages` branch.

Starts at the beginning: install, onboard, run a gateway, talk to your agent. The long-term goal is to document the full autonomy ladder jsclaw enables — from chatbot to orchestrator (see issue #1).
